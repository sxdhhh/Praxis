## P1 终端复制粘贴（5 条）

**准备**：设置页把模型配好；进终端 tab。

### 1. 长按出系统手柄  `[已实证]`

```
操作：终端里长按某一行文字
预期：出现安卓系统的选择手柄（水滴形），并弹出系统浮动菜单
      （翻译 / 复制 / 全选 / 朗读 / ⋮）
反例：出现自研的「已选中文本 / 复制 / 全选 / 完成」横条 = 失败
```

### 2. 可跨行扩展  `[未验]`

```
操作：长按选中一行 -> 拖动右侧手柄往下拖到第 3、4 行
预期：选区连续跨越多行，不中断
反例：拖到行外选区就断 = SelectionContainer 没覆盖整块
```

### 3. 复制粘贴内容一致  `[未验]`

```
操作：跑 `echo AAAABBBBCCCC` -> 选中 BBBB -> 复制
     -> 切到输入框 -> 粘贴
预期：粘贴出来正好是 BBBB，无多余空格、无缺字
重点：行尾不能带一串空格（buildAnnotatedScreen 要裁掉行尾空白）
```

### 4. ANSI 配色在选择态正确  `[未验]`

```
操作：跑 `ls --color=always /` -> 长按进入选择态
预期：选中的文字颜色仍是彩色（目录蓝、可执行绿）
反例：选中后全变白 = span 样式在 SelectionContainer 里丢了
```

### 5. 帧耗时判据  `[未验，目标的硬指标]`

```
操作：
  for i in $(seq 1 1000); do echo "line $i"; done
  然后滚动终端 + 敲几个字符
  adb shell dumpsys gfxinfo dev.praxis.debug

判据：50th 与 90th percentile 帧耗时
  <= 16ms  -> 通过，保持单块渲染
  >  16ms  -> 目标要求退回「仅选择态切单块、平时虚拟滚动」

注意：模拟器数字无意义（x86_64 且装不上包），必须真机。
```
