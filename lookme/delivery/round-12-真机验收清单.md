## A 线：网关六步（用「Agent2API 网关」这一家走全程）

| # | 步骤 | 期望 | 验证点 |
|---|---|---|---|
| A1 | 设置 → 网关 → 自定义提供商 → 内置家分区 → 找到「Agent2API 网关」 | 行存在，地址显示「待填」 | 新内置家入口（round-09） |
| A2 | 点「拉取模型清单」（先建不了账号没关系——这一步需要账号，见 A3） | 先跳到 A3 再回来 | —— |
| A3 | 账号池 → 添加账号 → 选「Agent2API 网关」→ **直填 API Key**（面板里建的网关密钥），地址填 `http://192.168.1.80:3065/v1`（或 `http://110.42.47.142:3065/v1`） | 保存成功，账号出现在账号池 | 登录方式只有「直填 API Key」—— 不该出现网页登录 |
| A4 | 回内置家 →「Agent2API 网关」→ 拉取模型清单 | 拉到全量模型（约 173 个，含 accio/trae/workbuddy…） | `/v1/models` 经网关 Key |
| A5 | 模型配置切到「网关」档案 → 模型选择器 | 出现网关模型列表（G1 修复的验证点） | 此前内置家在这里是空的 |
| A6 | 发一条消息 | 流式回复 | —— |
| A7 | 路由页 → 候选队列 | 显示账号位次；连发两条看粘性（同一对话第二条约走同一账号） | G6 粘性 |
| A8 | 把 Key 改错 → 重发 | 报错文案清晰（含「凭证」字样）；账号被标「需要重新登录」 | G5 降级 |
| A9 | 报表 / 日志（请求记录） | 出现今天的请求条目 | 报告有数据 |
| A10 | 发带图消息 | 若所选模型声明不支持图片 → 候选队列出现「该模型明确声明不支持图片输入」 | G3 |

## B 线：生图三步

| # | 步骤 | 期望 | 验证点 |
|---|---|---|---|
| B1 | 设置 → 本地生图 → 模型库 → 下载 **AnythingV5 (CPU)** | 下载完成显示「已安装」；中途杀进程再进 → 不显示已装 | G2（临时物隔离） |
| B2 | 回本地生图页 → 启动内置引擎 | 状态变「运行中」；等引擎自己退出（或重启 App）→ 按钮自动回「启动」 | G11（onExit） |
| B3 | 对话里让模型调用生图（512×512） | 出图进对话 + 自动存相册 | B 线验收句 |
| B4 | 选 **sd15npu** 模型 + 768 尺寸 | 工具返回 invalid_size，提示可用 512x512 —— 不出尺寸不对的图 | G4 |
| B5 | 选 z_image_turbo（DiT）→ 启动 | 如实拒绝（缺 `libdit_engine.so`），不假装能跑 | DiT 外部依赖 |
